{{ n }} in a fair pot draw

Put one hundred chits numbered 00 to 99 into a matka and pull one without looking. The chance that it reads {% if n < 10 %}0{% endif %}{{ n }} is exactly 1 in 100, or 1%. That is the same as for every other chit. No number is "due", "hot" or "lucky": the pot has no memory of earlier draws. {% if n < 10 %}In a single-digit draw from 0 to 9, the chance of {{ n }} is 1 in 10, or 10%.{% else %}A two-digit result like {{ n }} needs both digits to land: 1 in 10 for the {{ tensd }} and 1 in 10 for the {{ onesd }}, which multiplies to 1 in 100.{% endif %}

This is why any game that pays less than 100 times the stake on a 1-in-100 result loses money for the player over time. The odds calculator shows the arithmetic, and this lesson explains it step by step.
